# EDENFALL Landing Page

A fantasy-themed landing page project for **EDENFALL** built using HTML, CSS, and JavaScript.

## Preview

EDENFALL is a responsive landing page with animated sections, fantasy-inspired visuals, and smooth scrolling effects.

## Features

* Responsive design
* Animated UI sections
* Smooth scrolling navigation
* Custom SVG icons
* Download section
* Contact section
* Fantasy-inspired theme

## Built With

* HTML5
* CSS3
* JavaScript

## Installation

1. Clone the repository:

```bash
git clone https://github.com/clrkxd/EDENFALL_Landing-Page.git
```

2. Open the project folder:

```bash
cd EDENFALL_Landing-Page
```

3. Run the project by opening `index.html` in your browser.
